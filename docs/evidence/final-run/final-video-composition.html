Working demo · fresh live capture recorded October 17, 2026
The problem

“Open Zivil.” There is no project called Zivil.

Voice input mishears names. An agent that guesses can route work to the wrong project; one that never learns asks forever.

circe-graph keeps machines, projects, tasks and user-confirmed aliases as a graph. Agents ask first, learn only on confirmation, and answer with the graph path.

What is real, what is not

Read this before judging.

  • RealCodex CLI model output, the MCP tool calls it chose, FalkorDB responses and writes, process IDs. One continuous capture at 1× speed.
  • SyntheticThe machines, projects and tasks are seeded demo data, not live computers. The user's turns are predefined.
  • ScopeRouting selects a project. It does not open a workspace or execute coding tasks. Shell and delegation were disabled; sandbox read-only.
  • EditedTitle cards, the diagram, captions and the typeset query result were added in editing. Raw capture and logs are in the repository.
